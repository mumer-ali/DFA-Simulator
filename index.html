DFA Rules

  • DFA reads one input string symbol at a time.
  • There is only one path for an input from to the next state.
  • DFA does not accept the null move.
  • DFA can contain multiple accepting states.
  • Every state has a transition defined for each symbol.
  • The number of states in a DFA is finite.
  • DFA can recognize only regular languages.
